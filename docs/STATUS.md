# وضعیت پروژه (صادقانه) / Project Status

این فایل فقط چیزهایی را «انجام‌شده» می‌داند که واقعاً بررسی شده‌اند.

## بررسی‌شده (واقعاً اجرا شده)

| مورد | نتیجه |
|---|---|
| تست‌های بک‌اند (`backend/tests`) با pytest | 12 پاس، 1 رد شده (skip). تست‌های API به FastAPI نیاز دارند و در محیط توسعه نصب نبود؛ در GitHub Actions اجرا می‌شوند. |
| تست DSP نیتیو روی کامپیوتر (`android/audio-engine/src/test/cpp/dsp_test.cpp`) | همه پاس: تغییر گام ±12 و +7 نیم‌پرده با خطای زیر 4٪، تکرار اکو در تأخیر درست، دنباله ریورب، کاهش نویز، پایداری با پارامترهای افراطی، تشخیص کلیپ |

## نوشته شده ولی هنوز کامپایل/تست نشده

محیط توسعه به Android SDK و Maven دسترسی نداشت، پس این‌ها هنوز **کامپایل نشده‌اند**:

- همه کد Kotlin/Compose (برنامه و ماژول صوتی)
- پل JNI و اتصال Oboe
- تست‌های واحد Kotlin (`AudioOpsTest`)

ممکن است اولین اجرای GitHub Actions خطای کامپایل کوچکی نشان دهد. اگر شد، متن خطا را بفرستید تا اصلاح شود.

## هنوز روی گوشی واقعی تست نشده

تأخیر، افت صدا (dropout)، مسیر بلوتوث/هدست، تماس ورودی، مصرف باتری و حافظه. این موارد فقط با گوشی واقعی قابل بررسی‌اند.

| مورد | دلیل |
|---|---|
| خروجی MP3 | اندروید رمزگذار MP3 داخلی ندارد. خروجی WAV و M4A (AAC) پشتیبانی می‌شود. |
| Google Play Billing در اپ | نیاز به حساب Play Console و محصولات ثبت‌شده دارد. در اپ «پیکربندی نشده» نمایش داده می‌شود. |
| اعتبارسنجی خرید در بک‌اند | `/v1/billing/validate` عمداً خطای 501 می‌دهد تا کسی بدون خرید واقعی اعتبار نگیرد. نیاز به Service Account گوگل دارد. |
| مدل واقعی AI (تبدیل/شبیه‌سازی صدا) | نیاز به کلید یک سرویس AI روی سرور دارد. پیش‌فرض `none` است و هیچ نتیجه جعلی تولید نمی‌شود. |
| کلون صدای عصبی آفلاین | مدل محلی تست‌شده‌ای وجود ندارد، پس به‌عنوان قابلیت آفلاین معرفی نشده. |

| سرویس Foreground برای حالت زنده در پس‌زمینه | فعلاً ضبط فقط وقتی اپ باز است کار می‌کند (ضبط پنهان وجود ندارد). |
