# حریم خصوصی / Privacy

## فارسی
- صدایی که ضبط یا وارد می‌کنید روی **گوشی خودتان** پردازش می‌شود.
- چیزی به سرور فرستاده نمی‌شود، مگر خودتان عملیات ابری را شروع کنید و پیام اعلام آپلود را بپذیرید.
- میکروفون فقط وقتی استفاده می‌شود که شما دکمه ضبط یا حالت زنده را بزنید. ضبط پنهان یا پس‌زمینه وجود ندارد.
- مجوزها: میکروفون (با توضیح قبل از درخواست)، اینترنت و وضعیت شبکه. مجوز اضافه گرفته نمی‌شود.
- ساخت پروفایل صدا فقط با رضایت صریح و فقط برای صدای خودتان یا صدایی که اجازه استفاده دارید. جعل هویت افراد ممنوع است.
- خروجی تبدیل ابری با برچسب «تولید/تبدیل‌شده با AI» مشخص می‌شود (هدر `X-AI-Generated`).
- توکن دسترسی روی گوشی رمزنگاری‌شده نگه‌داری می‌شود (Android Keystore).
- اپ اطلاعات کارت یا پرداخت ذخیره نمی‌کند.
- حذف: نمونه صدا، پروفایل‌ها، داده سرور (`DELETE /v1/me`) و همه داده محلی از تنظیمات.
- پشتیبان‌گیری خودکار اندروید (`allowBackup`) خاموش است.

## English
- Recording and import are processed on-device.
- Audio is uploaded only after you start a cloud action and accept the upload notice.
- The microphone is used only while you press Record or Live. There is no hidden or background recording.
- Permissions: microphone (explained first), internet, network state.
- Voice profiles require explicit consent and may only be created for your own voice or a voice you have permission to use. Converted cloud audio is labeled as AI-generated.
- Your access token is stored encrypted. No payment data is stored.
- You can delete samples, profiles, server data, and all local data.

اگر سرور را خودتان اجرا می‌کنید، مسئول نگهداری و حذف داده‌های آن و رعایت قوانین محل خودتان هستید. قبل از انتشار عمومی، این متن را با نیازهای حقوقی خودتان تطبیق دهید.
